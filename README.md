## ◈ About LEGACY

**LEGACY** is a next-generation biometric payment concept designed to make everyday transactions simpler, faster and more secure.

By combining **fingerprint authentication** with **Near Field Communication (NFC)** technology, LEGACY introduces a new way to authorise payments without relying on traditional PIN-based interactions.

Whether paying at a merchant's terminal or transferring money to another person, users can authenticate transactions through a dedicated fingerprint reader.

## ✧ Key Features

- **Fingerprint Authentication** — Verify payment authorisations using biometric technology.
- **NFC Payments** — Enable contactless communication between compatible devices.
- **Finger-to-Machine** — Authorise payments using a dedicated fingerprint scanner integrated into a merchant's payment terminal.
- **Finger-to-Phone** — Authorise peer-to-peer payments through a designated fingerprint reader connected to the recipient's device.
- **Seamless Experience** — A streamlined payment journey designed around simplicity and convenience.
- **Security-Focused Design** — Built around biometric verification and secure transaction flows.
